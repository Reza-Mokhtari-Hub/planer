# برنامه‌ریزی هفتگی دانشجویی (`Planer`)

یک اپلیکیشن وب راست‌به‌چپ (RTL) و تمام‌عیار برای مدیریت برنامه هفتگی دانشجویان دندانپزشکی (مخصوصاً ترم ۵) که با **React**، **TypeScript**، **Tailwind CSS** و یک سرور سبک **Express** پیاده‌سازی شده است.

ایده اصلی این پروژه از نیاز به یک برنامه‌ریز واقعی برای چیدن کلاس‌های سنگین کلینیک و پری‌کلینیک، تایم‌های مطالعه، وعده‌های ثابت و جلسات ورزش هفتگی شکل گرفت؛ طوری که هم روی موبایل و هم دسکتاپ سریع باشد، بدون نیاز به دیتابیس خارجی روی مرورگر ذخیره شود و خروجی چاپی و PDF تمیزی با فونت فارسی بدهد.

---

## ویژگی‌ها و بخش‌های برنامه

### ۱. داشبورد روزانه و مرور سریع
- نمایش خودکار تاریخ شمسی روز، درصد پیشرفت کل هفته و آمار کارهای انجام‌شده / باقی‌مانده.
- لیست فعالیت‌های امروز با امکان تیک‌زدن سریع، پخش افکت صوتی ملایم (Web Audio API) و جشن اتمام کار.
- نمودار ستونی بهره‌وری ۷ روز هفته و فرم **بازتاب هفتگی (Weekly Reflection)** با ثبت نقاط قوت، چالش‌ها، بهبودها و امتیاز ۱ تا ۵ ستاره.

### ۲. جدول هفتگی (ماتریس و تایم‌لاین)
- دو نمای مجزا: **نمای ماتریسی** (۹ بازه زمانی در ۷ روز هفته) و **نمای کارتی تایم‌لاین** برای هر روز.
- جابجایی کارها با کشیدن و رها کردن (**Drag & Drop**) بین روزها و بازه‌های زمانی مختلف.
- جستجوی آنی و فیلتر هم‌زمان بر اساس دسته‌بندی، اولویت و وضعیت انجام.
- تعریف خودکار برنامه پیشنهادی ترم ۵ دندانپزشکی (۶۳ فعالیت از جمله فارماکولوژی، ترمیم، پروتز، اندو، رادیولوژی، ۳ جلسه ورزش در جمعه‌ها، یک‌شنبه‌ها و سه‌شنبه‌ها، تایم ثابت ناهار ۱۲ تا ۱۳ و شام ۲۱:۳۰).

### ۳. آمار و پایش عادت‌های کلیدی
- مقایسه کارهای انجام‌شده و مانده به تفکیک هر روز و نمایش سهم هر دسته‌بندی.
- کارت‌های پایش اختصاصی برای **۳ جلسه ورزش هفتگی**، **نظم ناهار (۱۲:۰۰–۱۳:۰۰)** و **تایم شام و استراحت شبانه (۲۱:۳۰)**.

### ۴. آرشیو و چرخه تکرار هفته
- آرشیو کامل برنامه هر هفته به همراه یادداشت‌های بازتاب هفتگی.
- امکان بازیابی هفته‌های قبلی یا **تکرار ساختار هفته** برای شروع هفته جدید (با گزینه‌های آرشیو خودکار هفته فعلی و صفرکردن وضعیت تیک‌ها).

### ۵. مرکز خروجی و چاپ استاندارد (PDF / PNG / JSON)
- رندر زنده بوم خروجی با فونت فارسی **Vazirmatn** روی Canvas.
- پشتیبانی از دو قالب **جدول ماتریسی** و **چک‌لیست ۷ روزه** در دو حالت **افقی (Landscape)** و **عمودی (Portrait)**.
- دانلود مستقیم **PDF** (با `jsPDF`)، چاپ مستقیم مرورگر، خروجی تصویر **PNG** و پشتیبان‌گیری / بازیابی کامل اطلاعات در قالب **JSON**.

### ۶. مشاور و تحلیلگر برنامه (Gemini Mentor)
- بخش گفتگوی تعاملی و تحلیل برنامه درسی که خلاصه واقعی برنامه هفتگی جاری را از طریق مسیر `/api/ai/stream` روی سرور بررسی می‌کند و به‌صورت استریم (SSE) پیشنهادهای زمان‌بندی، ریکاوری بعد از کلینیک و برنامه‌ریزی مرور دروس را برمی‌گرداند.
- دارای ۴ دکمه تحلیل آماده و امکان انتخاب بین چند مدل پاسخ‌دهی.

### ۷. ۴ پوسته روشن و شخصی‌سازی کامل
- ۴ تم روشن اختصاصی با حال‌وهوای پرانرژی:
  - **آفتابی روشن** (`Energetic Light`)
  - **شکوفه بهاری** (`Spring Blossom`)
  - **اقیانوس نعنایی** (`Ocean Mint`)
  - **پرتقالی گرم** (`Sunshine Warm`)
- امکان تغییر روز شروع هفته، فعال/غیرفعال‌کردن افکت صدا، تعریف دسته‌بندی‌های سفارشی و مدیریت کامل داده‌ها.

## تکنولوژی‌های استفاده‌شده

- **Frontend:** React 19, TypeScript, Tailwind CSS v4, Vite, Lucide Icons
- **Backend:** Node.js, Express (ارائه فایل‌ها و مسیر استریم `/api/ai/stream`)
- **Export & Media:** HTML5 Canvas, `jsPDF`, Web Audio API
- **Fonts:** Vazirmatn & Plus Jakarta Sans (به‌صورت محلی در `public/fonts`)
- **Storage:** `localStorage` مرورگر (آفلاین و بدون نیاز به سرور دیتابیس)

## نصب و اجرای محلی

۱. مخزن را کلون کنید و وارد پوشه پروژه شوید:

```bash
git clone https://github.com/Reza-Mokhtari-Hub/planer.git
cd planer
```

۲. پکیج‌ها را نصب کنید:

```bash
npm install
```

۳. یک فایل `.env` در ریشه پروژه بسازید (مطابق `.env.example`) و در صورت استفاده از بخش تحلیلگر برنامه، کلید API را در آن قرار دهید:

```env
GEMINI_API_KEY=your_api_key_here
PORT=3000
```

۴. سرور توسعه را اجرا کنید:

```bash
npm run dev
```

برنامه روی آدرس `http://localhost:3000` در دسترس خواهد بود.

### اسکریپت‌های مفید

```bash
npm run lint     # بررسی تایپ‌های TypeScript
npm run build    # ساخت خروجی نهایی در پوشه dist
npm start        # اجرای سرور در حالت نهایی
```

## ساختار پوشه‌ها

```text
├── public/fonts/        # فونت‌های Vazirmatn و Plus Jakarta Sans
├── src/
│   ├── components/      # کارت کارها، مودال ویرایش، انتقال، مرکز خروجی و کانفتی
│   ├── data/            # داده‌های پیش‌فرض برنامه ترم ۵ دندانپزشکی
│   ├── screens/         # صفحات داشبورد، برنامه هفتگی، آمار، آرشیو، مشاور و تنظیمات
│   ├── types/           # مدل‌ها و تایپ‌های TypeScript
│   └── utils/           # تاریخ شمسی، تم‌ها، صدا، ذخیره‌سازی و موتور رندر PDF/PNG
├── server.ts            # سرور Express و مسیر SSE
└── vite.config.ts       # تنظیمات Vite و Tailwind CSS
```
